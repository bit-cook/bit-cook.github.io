生成源码（供 Agent 修改）

整套标识由脚本生成：改 build_family.py 里的几何数字即可重塑标志， 依次运行下面四条命令可完整复现全部交付物。

$ # 完整复现（需 Python 3.12+ / pip install pillow fonttools uharfbuzz）
$ python build_family.py   # 生成 svg/ 全部标志
$ python banner.py         # 生成中英文横幅
$ python render_pngs.py    # 渲染 PNG + favicon.ico
$ python brand.py          # 生成品牌规范页

# 标志几何速查（64 网格）
砖形  超级椭圆 n=5, a=29, 描边 4.5
符号  箭号 (18.6,18.2)→(30.8,31.0)→(18.6,43.8)
光标  (38.6,43.8)→(48.4,43.8), 笔画 6.2 圆头

使用规则速记

  • 净空 = 图标高度的 1/4；最小可用尺寸 16px（用 favicon.svg 专版）。
  • 暗色背景用 logo-mark-dark.svg；单色场景用 logo-mark-mono.svg，不要自行去色彩色版。
  • 不拉伸、不旋转、不改配色、不加投影或立体效果。
  • 中文主标语「一条命令，Agent 就位」；英文「One command. Agent ready.」。
